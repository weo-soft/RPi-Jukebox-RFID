# Milestone 8 — Optional: Mopidy Migration (MPD → Mopidy)

## Status: **Optional** — Independent of Milestones 0-7

Dieser Milestone kann zu jedem Zeitpunkt — vor, während oder nach der
MediaProvider-Implementierung — durchgeführt werden. Er hat **keine Abhängigkeiten**
zu den anderen Meilensteinen und erfordert **keine Python-Code-Änderungen**.

## Ziel

MPD durch Mopidy ersetzen, um Spotify-Integration (via mopidy-spotify) und
andere Mopidy-Erweiterungen zu ermöglichen. Mopidy spricht das MPD-Wire-Protokoll
identisch auf Port 6600, sodass `python-mpd2` und alle bestehenden Komponenten
unverändert weiterarbeiten.

## Abhängigkeiten

- **Keine** — dieser Meilenstein ist ein reiner Deployment-Wechsel
- Keine Python-Code-Änderungen nötig
- Keine MediaProvider-Meilensteine als Voraussetzung
- Kann vor, während oder nach M0-M7 durchgeführt werden

## Hintergrund

```
MPD (Music Player Daemon)           Mopidy
─────────────────────────           ─────────────────────────
• C/C++ codebase                    • Python codebase
• Leichtgewichtig (low resource)     • Höherer Ressourcenverbrauch
• Keine Erweiterungen                • Extension-System (Spotify, SoundCloud, ...)
• MPD-Protokoll (native)            • MPD-Protokoll (kompatibel)
• Port 6600                         • Port 6600
• mpd.conf                           • mopidy.conf
```

**Warum Mopidy?** Mopidy's Extension-System erlaubt die Integration von
Streaming-Diensten, die MPD nicht unterstützt (Spotify, YouTube, SoundCloud,
Google Play Music). Die `mopidy-spotify`-Extension behandelt alle
Spotify-Protokoll-Details (Authentifizierung, DRM, Streaming, Metadaten)
und stellt Spotify-Tracks als normale MPD-Tracks dar.

## Design-Entscheidungen

1. **Reines Deployment-Change** — kein Python-Code wird geändert. `PlayerMPD`
   verwendet `python-mpd2` und verbindet zu `localhost:6600` — ob dort `mpd`
   oder `mopidy` antwortet, ist transparent.

2. **Installer-Option** — Der Installer (Milestone 7) bietet eine Option
   "Mopidy statt MPD installieren?" an. Default: MPD (bewährt,leichtgewichtig).

3. **Konfiguration bleibt ähnlich** — `music_directory` wird von `mpd.conf` nach
   `mopidy.conf` übertragen. Mopidy hat andere Sektionen für Audio-Output, aber
   die für die Jukebox relevanten Einstellungen sind 1:1 übertragbar.

4. **Mopidy ist ein MPD-Ersatz, keine Ergänzung** — es wird entweder MPD oder
   Mopidy auf Port 6600 betrieben, nie beide gleichzeitig.

## Scope

### Änderungen im Installer (Milestone 7 / Installation)

- **`installation/routines/customize_options.sh`**: Neue Option `_option_mopidy()`
- **`installation/routines/setup_mpd.sh`** → `setup_audio_backend.sh`: Installiert
  entweder MPD oder Mopidy (je nach Benutzerauswahl)
- **Konfigurationsdatei**: `mopidy.conf` wird aus Template generiert (analog zu `mpd.conf`)

### Installer-Routine: `_option_mopidy()` in `customize_options.sh`

```bash
_option_mopidy() {
  clear_c
  print_c "----------------------- AUDIO BACKEND -----------------------
By default, the Jukebox uses MPD (Music Player Daemon) as the audio backend.
MPD is lightweight, stable, and handles local files well.

Optionally, you can install Mopidy instead of MPD. Mopidy speaks the same
protocol as MPD but supports extensions for streaming services:
  • Spotify (via mopidy-spotify)
  • SoundCloud, YouTube, and more

Trade-offs:
  • Mopidy uses more RAM and CPU than MPD
  • Spotify extension requires a Spotify Premium account
  • Mopidy is less tested on Raspberry Pi than MPD

Use Mopidy instead of MPD? [y/N]"
  read -r response
  case "$response" in
    [yY][eE][sS]|[yY])
      USE_MOPIDY=true
      print_c "  → Mopidy will be installed instead of MPD."
      
      # Ask for Spotify credentials if Mopidy is chosen
      print_c "
Do you want to enable Spotify integration? [y/N]"
      read -r spotify_response
      case "$spotify_response" in
        [yY][eE][sS]|[yY])
          ENABLE_SPOTIFY=true
          print_c "
  To use Spotify with Mopidy, you need:
    1. A Spotify Premium account
    2. A Spotify Developer application (https://developer.spotify.com/dashboard)
    3. Client ID and Client Secret from the application

  These will be stored in shared/settings/secrets.conf"
          ;;
        *)
          ENABLE_SPOTIFY=false
          ;;
      esac
      ;;
    *)
      USE_MOPIDY=false
      print_c "  → MPD will be installed (default)."
      ;;
  esac
  
  log "USE_MOPIDY=${USE_MOPIDY}"
  log "ENABLE_SPOTIFY=${ENABLE_SPOTIFY}"
}
```

### Angepasst: `setup_audio_backend.sh` (ersetzt `setup_mpd.sh`)

```bash
_setup_mpd() {
  print_lc "  Install MPD (Music Player Daemon)"
  sudo apt-get install -y mpd
  # ... existing MPD configuration ...
}

_setup_mopidy() {
  print_lc "  Install Mopidy (MPD-compatible with extension support)"
  
  # Add Mopidy APT repository
  sudo mkdir -p /etc/apt/keyrings
  wget -q -O /etc/apt/keyrings/mopidy-archive-keyring.gpg \
    https://apt.mopidy.com/mopidy.gpg
  sudo wget -q -O /etc/apt/sources.list.d/mopidy.list \
    https://apt.mopidy.com/bullseye.list
  sudo apt-get update
  sudo apt-get install -y mopidy mopidy-local
  
  # Install Spotify extension if requested
  if [[ "$ENABLE_SPOTIFY" == "true" ]]; then
    print_c "    Installing mopidy-spotify extension..."
    sudo apt-get install -y mopidy-spotify
    
    # Enable Spotify in mopidy.conf
    sed -i 's/enabled = false/enabled = true/' /etc/mopidy/mopidy.conf
  fi
  
  # Copy mopidy.conf template
  cp -f "${INSTALLATION_PATH}/resources/default-settings/mopidy.default.conf" \
        /etc/mopidy/mopidy.conf
  
  # Set music library path (same as MPD used)
  MUSIC_LIB_PATH=$(grep music_directory ~/.config/mpd/mpd.conf 2>/dev/null | cut -d'"' -f2 || echo "/home/pi/RPi-Jukebox-RFID/shared/audiofolders")
  sed -i "s|{MUSIC_LIBRARY_PATH}|${MUSIC_LIB_PATH}|g" /etc/mopidy/mopidy.conf
  
  # Enable and start Mopidy service
  sudo systemctl enable mopidy
  sudo systemctl start mopidy
  
  # Disable MPD if it was previously installed
  if systemctl is-active --quiet mpd; then
    sudo systemctl stop mpd
    sudo systemctl disable mpd
  fi
}

setup_audio_backend() {
  if [[ "$USE_MOPIDY" == "true" ]]; then
    run_with_log_frame _setup_mopidy "Install Mopidy Audio Backend"
  else
    run_with_log_frame _setup_mpd "Install MPD Audio Backend"
  fi
}
```
